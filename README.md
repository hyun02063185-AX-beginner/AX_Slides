# AX 강의 슬라이드

웹으로 만든 강의 슬라이드입니다. GitHub Pages로 배포합니다. 설치나 빌드는 필요 없습니다.

| 폴더 | 내용 |
| --- | --- |
| `2026-11_demoday/` | 데모데이 15분 (21시간 과정의 첫 15분) |
| `2026-11_demoday/demo/` | 8번 AI 시연 자료(`corpus.json`), 리허설 기록(`recorded.json`), 재현 시험 페이지(`test.html`) |
| `assets/` | 슬라이드 엔진(`deck.js`, `deck.css`), AI 시연(`ai-demo.js`), 글꼴(Pretendard, OFL) |

강의 자료 속 회사·사람·번호는 모두 실습용 가상 데이터입니다.

## 발표할 때 쓰는 키

| 키 | 하는 일 |
| --- | --- |
| → ↓ Space PageDown Enter | 다음 (리모컨 가능) |
| ← ↑ PageUp Backspace | 이전 |
| p | 발표자 화면: 경과 시간, 이 장의 계획 시간, 말할 것, 다음 장 |
| t | 타이머 다시 시작 (0번에서 넘기면 자동 시작) |
| s | 그 장의 1분 타이머 시작 |
| r | 8번에서 AI 실시간 실행 |
| k | AI 연결 설정 (키는 이 브라우저에만 저장) |
| b | 화면 가리기 |
| f | 전체 화면 |

발표자 화면의 시계 색: 초록 = 계획보다 빠름, 주황 = 다음 장 계획 시각을 넘김, 빨강 = 30초 이상 늦음.

## 8번 AI 시연

- 기본은 **리허설 기록**(`recorded.json`)을 보여 줍니다. "기록 보기" 버튼.
- 인터넷과 키가 있으면 **"지금 실행"(r)** 으로 같은 질문을 실시간으로 던집니다. 8초가 넘으면 자동으로 리허설 기록을 띄우고 "리허설 기록 (실시간 응답 지연)"이라고 표시합니다.
- 정리 전 = 다온오피스 파일 20개의 글자, 정리 후 = 같은 20개 + 파일마다 '최신·이전·확정'을 적은 자료 목록 1개. 카톡 캡처·스캔·사진 4개는 글자를 읽을 수 없는 상태 그대로 둡니다.
- API 키는 코드에 넣지 않습니다. 발표 노트북에서 `k` → 키 입력 → "연결 시험" → "저장".
- 기본값: 방식 **Claude (Anthropic Messages)**, 주소 `https://copa.codyssey.kr` (`/v1/messages`로 호출), 모델 `claude-haiku-4`(빠름), `temperature 0`(결과를 최대한 고정), `max_tokens 300`. 더 정확한 답이 필요하면 모델을 `claude-sonnet-4`로 바꿔 재현 시험을 다시 합니다.
- 설정 창에서 방식을 "OpenAI 호환"으로 바꾸면 `/v1/chat/completions`로 호출합니다.
- "연결 시험"에서 `Failed to fetch`가 나오면 브라우저에서 직접 호출이 막힌 것(CORS)일 수 있습니다. 그때는 리허설 기록만 씁니다.

### 재현 시험 → 리허설 기록 만들기

1. `2026-11_demoday/demo/test.html`을 엽니다 (배포 주소 뒤에 `/2026-11_demoday/demo/test.html`).
2. "설정"에서 키를 넣고, 질문과 횟수(예: 10~20회)를 고른 뒤 "시험 시작".
3. 정리 전·후 정답 수가 정직하게 갈리는지 봅니다. 갈리지 않으면 숨기지 말고 질문을 바꾸거나 메시지를 "근거 확인"으로 바꿉니다.
4. "기록 파일 내려받기"로 받은 `recorded.json`을 `2026-11_demoday/demo/`에 덮어써서 커밋합니다.

## 배포 (GitHub Pages)

저장소 Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, 폴더: **/(root)** → Save.
1~2분 뒤 `https://hyun02063185-ax-beginner.github.io/AX_Slides/` 에서 열립니다. 이후에는 main에 올리면 자동으로 반영됩니다.

## 인터넷이 없을 때

- **PDF 백업**: 슬라이드 화면에서 Ctrl+P → 대상 "PDF로 저장" → 한 장에 슬라이드 하나씩 저장됩니다(단계 등장 효과는 모두 펼쳐진 상태).
- **노트북에서 바로 열기**: 저장소를 내려받아 폴더에서 `python -m http.server` 실행 후 `http://localhost:8000/2026-11_demoday/`. (파일을 더블클릭해 열면 8번의 기록 파일을 읽지 못합니다)
